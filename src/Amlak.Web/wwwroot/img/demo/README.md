# Demo photos

Real property photos for the development seed (`Data/DevSeed.cs`). Run `tools/fetch-demo-photos.sh` once to download them from Unsplash, then commit them (Unsplash License: free for commercial and
non-commercial use, no permission or attribution required). The list of photos is `tools/demo-photos.tsv`.

The seed attaches a photo only when its file exists here, so the site still runs without them.
