# کانال تلگرام و ربات بله

هر آگهی منتشرشده در کانال‌های تنظیم‌شده پست می‌شود. هر کانال مستقل است؛ می‌توانید فقط یکی را فعال کنید.

> **وضعیت راستی‌آزمایی:** کد با Bot API ساختگی تست شده (۸ تست). با سرور واقعی تلگرام و بله هنوز امتحان نشده است.

## تلگرام

۱. در تلگرام با `@BotFather` ربات بسازید (`/newbot`) و **توکن** را بگیرید.
۲. یک کانال بسازید و ربات را به‌عنوان **Administrator** با اجازهٔ «Post messages» و «Edit messages» و «Delete messages» اضافه کنید.
۳. شناسهٔ کانال: برای کانال عمومی `@نام_کانال`؛ برای خصوصی شناسهٔ عددی منفی مثل `-100123456789`.

## بله

۱. در بله با `@botfather` ربات بسازید و توکن را بگیرید.
۲. ربات را در کانال/گروه مقصد اضافه و ادمین کنید.
۳. `chat_id` مقصد را بگیرید (مثلاً از `getUpdates` پس از ارسال یک پیام در کانال).

## تنظیم (فقط user-secrets یا متغیر محیطی)

در پوشهٔ `Src/Host/Amlak.ServiceHost`:

```bash
dotnet user-secrets set "Telegram:BotToken" "<توکن>"
dotnet user-secrets set "Telegram:ChatId" "@نام_کانال"
dotnet user-secrets set "Bale:BotToken" "<توکن>"
dotnet user-secrets set "Bale:ChatId" "<شناسه>"
dotnet user-secrets set "Site:BaseUrl" "https://دامنه-شما.ir"
```

در سرور (متغیر محیطی با دو زیرخط): `Telegram__BotToken`, `Telegram__ChatId`, `Bale__BotToken`, `Bale__ChatId`.

**توکن را هرگز در چت، کد، فایل تنظیمات یا مخزن نگذارید.** اگر لو رفت، در BotFather با `/revoke` توکن جدید بگیرید.

## آدرس API

| کانال | پیش‌فرض | تغییر |
|---|---|---|
| تلگرام | `https://api.telegram.org` | `Telegram:ApiBase` |
| بله | `https://tapi.bale.ai` | `Bale:ApiBase` |

تلگرام در ایران فیلتر است. اگر سرور داخل ایران است، `Telegram:ApiBase` را روی یک واسط (reverse proxy) بگذارید که `/bot<توکن>/...` را به تلگرام می‌رساند. به واسطِ شخص ثالث توکن ندهید؛ واسط خودتان را بالا بیاورید.

```
🏠 آپارتمان ۱۲۰ متری نوساز
📍 تهران، سعادت‌آباد
📐 ۱۲۰ متر | ۳ خواب

#فروش #تهران #سعادت_آباد
```

- اگر آگهی عکس دارد، **عکس اول** با این متن به‌عنوان کپشن فرستاده می‌شود (کپشن حداکثر ۱۰۰۰ نویسه).
- متن ساده است (بدون HTML/Markdown) تا در هر دو پیام‌رسان یکسان نمایش داده شود.

## رفتار

| رویداد | اثر در کانال |
|---|---|
| انتشار آگهی | پست جدید |
| ذخیرهٔ تغییرات آگهی منتشرشده | ویرایش همان پیام |
| لغو انتشار، بسته‌شدن، حذف آگهی | حذف پیام |
| شکست ارسال | خطا در صفحهٔ ویرایش؛ با «همگام‌سازی دوباره» یا ذخیرهٔ بعدی تکرار می‌شود |

## رفع خطا

| پیام | علت محتمل |
|---|---|
| `Unauthorized` | توکن اشتباه یا باطل‌شده |
| `chat not found` | `ChatId` اشتباه، یا ربات هنوز عضو کانال نیست |
| `not enough rights to send/edit/delete` | ربات ادمین نیست یا اجازه ندارد |
| `ارتباط با سرویس برقرار نشد` | فیلتر/قطعی شبکه؛ `ApiBase` یا اتصال سرور را بررسی کنید |
| `message to edit not found` / `can't be edited` | پیام را دستی پاک کرده‌اید یا ویرایش آن مجاز نیست؛ آگهی را لغو و دوباره منتشر کنید |

## محدودیت‌های فعلی

- فقط عکس اول ارسال می‌شود (آلبوم: CHN-07).
- ارسال داخل درخواست ادمین است و صف پس‌زمینه ندارد (CHN-08).
- تغییر عکس‌ها پس از انتشار در پیام کانال اعمال نمی‌شود.
