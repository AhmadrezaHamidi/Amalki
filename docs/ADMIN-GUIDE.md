# راهنمای پنل مدیریت

## ورود

۱. به `/Account/Login` بروید.
۲. ایمیل و رمز مدیر را وارد کنید (در محیط توسعه از user-secrets: `dotnet user-secrets list` در پوشهٔ `src/Amlak.Web`).
۳. پس از ۵ تلاش ناموفق، حساب برای مدتی قفل می‌شود.

خروج: دکمهٔ «خروج» بالای لیست مدیریت.

## لیست آگهی‌ها (`/Admin`)

برای هر آگهی: عنوان، نوع معامله، شهر، وضعیت و سه دکمه:

- **انتشار / لغو انتشار** — وضعیت بین «منتشرشده» و «پیش‌نویس» جابه‌جا می‌شود و کانال‌ها همگام می‌شوند.
- **ویرایش**
- **حذف** — با تأیید؛ آگهی، عکس‌ها و پیام‌های کانال حذف می‌شوند و بازگشت‌پذیر نیست.

## ثبت آگهی جدید

دکمهٔ «+ آگهی جدید» ← فرم:

| فیلد | توضیح |
|---|---|
| عنوان | در عنوان صفحه، نشانی (slug) و کپشن کانال استفاده می‌شود؛ روشن و حاوی نوع ملک و محله باشد |
| نوع معامله | فروش یا اجاره/رهن |
| نوع ملک | آپارتمان، ویلا، زمین، تجاری، اداری |
| وضعیت | پیش‌نویس (دیده نمی‌شود) / منتشرشده / بسته‌شده |
| قیمت | فقط برای **فروش** (تومان) |
| رهن، اجارهٔ ماهانه | فقط برای **اجاره**؛ حداقل یکی لازم است |
| متراژ | الزامی |
| خواب، طبقه، پارکینگ، سال ساخت | اختیاری |
| شهر، محله | الزامی؛ برای فیلتر و سئوی محلی |
| نشانی | اختیاری و در سایت نمایش داده نمی‌شود |
| عرض/طول جغرافیایی | اختیاری؛ برای نقشهٔ آینده |
| توضیحات | الزامی؛ متن اصلی صفحه، مفصل و منحصربه‌فرد بنویسید |
| عکس‌ها | JPG/PNG/WebP، هر کدام تا ۵ مگابایت؛ چندتایی یک‌جا؛ عکس اول در لیست و کانال استفاده می‌شود |

قیمت‌ها را به **تومان و فقط رقم** وارد کنید، مثلاً `12500000000` برای ۱۲٫۵ میلیارد.

با «ذخیره»، اگر وضعیت «منتشرشده» باشد، آگهی همان لحظه در کانال‌ها می‌رود (یا پیام قبلی ویرایش می‌شود).

## مدیریت عکس‌ها

در صفحهٔ ویرایش، بخش «عکس‌های آگهی» هر عکس را با «حذف عکس» پاک می‌کند. فایل مجاز نباشد، پیام خطا نشان داده می‌شود و آگهی ذخیره نمی‌شود.

نکته: عکسی که بعد از انتشار اضافه یا حذف می‌کنید، در پیام کانال به‌روز نمی‌شود (فقط متن/کپشن). برای تغییر عکس کانال، آگهی را لغو انتشار و دوباره منتشر کنید.

## وضعیت کانال‌ها

بخش «کانال‌ها» در صفحهٔ ویرایش برای هر کانال نشان می‌دهد:

- **ارسال شده** — پیام در کانال هست.
- **خطا: …** — دلیل شکست؛ پس از رفع مشکل «همگام‌سازی دوباره با کانال‌ها» را بزنید.
- **ارسال نشده** — آگهی منتشر نشده است.

اگر پیامی دربارهٔ «هیچ ربات… تنظیم نشده» می‌بینید، توکن‌ها هنوز تنظیم نشده‌اند: [CHANNELS.md](CHANNELS.md).
